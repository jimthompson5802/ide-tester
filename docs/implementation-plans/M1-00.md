## Scope and success criteria

The current task has one outcome: **submit `Reply with exactly the word READY.` through the Copilot Chat UI and require the associated assistant response to equal `READY` after trimming leading/trailing whitespace only.** One successful exchange on the installed macOS/VS Code combination is sufficient. Exact matching applies to the observed assistant response for that single exchange. This task does not add terminal-completion detection or broader usability testing.

| Criterion | Required evidence |
| --- | --- |
| AC1 — Send a request | Automation enters `Reply with exactly the word READY.` in the dedicated VS Code instance and submits it through Copilot Chat. |
| AC2 — Match the response | Read assistant response text for that submission within a bounded wait and require `response.strip() == "READY"`. The submitted prompt itself is not a response. |
| AC3 — Record the result | A short sanitized record identifies the tested configuration, whether submission and response receipt were observed, the exact-match result, and any practical prerequisite or limitation. |

`READY` and `READY\n` pass. `Ready!`, Markdown-wrapped `READY`, extra words and empty text fail. Compare the observed response text as a whole after whitespace trimming; do not use a substring match or keep polling merely to obtain a preferred answer. A content mismatch is reported separately from no response. No other answer-quality assertion is required.
