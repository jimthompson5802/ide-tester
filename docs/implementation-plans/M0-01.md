**Source:** [GitHub issue #2](https://github.com/jimthompson5802/ide-tester/issues/2).
**Status:** Baseline inspection completed on 2026-10-20 following the developer's implementation request; developer validated the results on 2026-10-20. No later story is authorized.
**Story:** As a developer preparing the test host, I want a documented host and checkout baseline so that setup targets the intended environment and preserves existing work.

## Scope and current state

Implement only Phase 1 of the [Milestone 0 implementation plan](../../specifications/ide-milestone0-implementation-plan.md#phase-1--establish-the-host-and-checkout-baseline), following the [setup guide](../../specifications/ide-milestone0-environment-setup.md). Establish local evidence of host identity, checkout identity, Git availability, ignore behavior, and existing environment state. Preserve existing work and report blockers before dependent setup.

Prerequisites are a macOS host, terminal access, this checkout, and network access for any required download. No earlier story is required. M0-02 and subsequent setup depend on this baseline; they are outside this plan.

Excluded: uv installation or updates, Python installation or environment creation, project initialization, shared Python pins, Python libraries, compiler tools, VS Code or Copilot configuration, authentication, GUI automation, Windows setup, and harness implementation. The only conditional software installation in this story is an approved prebuilt Git distribution if Git is unavailable. Do not remove pre-existing compiler tools.

Verified during planning:

- The [README](../../README.md) and [repository instructions](../../AGENTS.md) identify a design-only repository without runnable harness tests. No project metadata, lockfile, or test implementation was found in the inspected repository files.
- The initial `git status --short` output was empty. Execution must capture a new baseline rather than rely on this planning observation.
- [`.gitignore`](../../.gitignore) contains `.venv/`, `.python-version`, and `/reports/*`. `git check-ignore -v` identified all three rules for the proposed paths; `git ls-files -- .venv .python-version` returned no paths.
- The existing milestone plan covers all five M0 stories; this document refines M0-01 only. No matching story-specific plan existed.

Not established by planning: macOS version, architecture, Git distribution provenance, environment ownership/compatibility, uv availability or installation method, and network download readiness. These are execution observations, not assumptions of success. No material design decision remains open; unknown host conditions have bounded inspection and blocker handling below.

## Technical approach

Use direct host and Git inspection, an ignored detailed evidence record, and a brief tracked results section in this plan; no application code, dependency, wizard, or test framework is needed. Proposed execution artifact: `reports/milestone0-setup.local.md`. Verify it is ignored and untracked before writing it. Append a dated M0-01 section if it already exists, preserving prior content. Keep absolute paths and raw output local; record sanitized findings in the execution results section below. Keep that section brief; raw command transcripts remain in the local evidence file.

Record each check's timestamp, command, exit status, relevant output, interpretation, and any blocker. Distinguish an absent optional installation from a broken inspection: absent uv or `.venv` is an expected baseline state and does not require installation in this story. A failure to establish required host, checkout, Git, ignore, or evidence safety properties blocks completion and dependent setup. Existing environment conflicts must be recorded and block later mutation until resolved.
